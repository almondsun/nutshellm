# Demo script (under three minutes)

## 0:00–0:25 — Problem

Show Nuto on the landing page and say: “Your context, in a nutsheLLM.” Explain that
agents repeatedly send large source files, logs, tool output, and history. The shell
can be trimmed, but the kernel—the facts the task needs—must stay intact.

## 0:25–1:15 — Live comparison

Run the checkout incident scenario. While it executes, point out the baseline and
optimized paths use the same model and parameters. Open the completed result:

- quality verdict;
- baseline versus optimized tokens;
- PariTok-attributed savings;
- exact incident facts;
- latency and separately reported evaluation overhead.

## 1:15–2:05 — Inspectability and fallback

Open context decisions. Show repetitive telemetry compressed, immutable timestamps
and errors at 100% recall, and duplicate content removed separately. Show the safety
ladder and explain `L2 → L1 → L0 → original`.

## 2:05–2:35 — Real integration

Show the API request and the PariTok dashboard evidence for the same hosted-key
traffic. Briefly show the code-debugging scenario’s deterministic validator.

## 2:35–2:55 — Close

State the measured median saving and quality pass rate from the final benchmark
export: **52.2% median input saving and 100% deterministic passes (3/3)**. Do not
substitute the landing page's historical aggregate percentage. Close on Nuto with:
“Compress the shell. Guard the kernel. Prove the answer. Your context, in a
nutsheLLM.”
